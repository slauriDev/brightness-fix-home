Приложение создано для решения проблемы с управлением яркостью на устройствах с GSI-прошивками. На многих кастомных системах стандартный ползунок яркости либо работает некорректно, либо вообще не влияет на подсветку. Это приложение позволяет вручную управлять яркостью напрямую через системный файл, используя root-права.

Brightness Fix for GSI

An app designed to fix brightness control issues on devices with GSI custom ROMs. On many custom systems, the standard brightness slider either works incorrectly or doesn't affect the backlight at all. This app allows you to manually control brightness directly via the system file using root privileges.

Completely free · No ads · Open source (GitHub repository)
